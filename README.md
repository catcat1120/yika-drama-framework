# 一卡研究室

一个用于理解短剧“一卡内容框架”的中文交互式学习站。

## 网站内容

- 以“观众期待 → 信息差 → 事件推进 → 临界卡点”解释一卡的内容功能。
- 提供按期待类型筛选的案例卡，以及一题可交互的卡点判断练习。
- 明确区分公开分析观点、用户提供的框架归纳与本站推演；未核片的案例标为“待逐集核验”。
- 附公开资料链接。没有上传用户的 Word 课件、剧集视频或其他私人文件。

## 运行与发布

这是无需构建工具的静态网站。直接打开 `index.html` 即可浏览。发布时可将 GitHub Pages 来源设为 `main` 分支根目录。

## 相关项目

截至 2026-09-30 的有限检索中，发现 [short-video-shot-analysis](https://github.com/gxinxing/short-video-shot-analysis)（通用短视频拉片助手）、[拉片工具](https://github.com/tonychanfilms/tonychanfilms.github.io)（视频播放与结构化笔记）、[红果短剧编剧课程存档](https://github.com/kunhai-88/hongguo-shortdrama-screenwriting-course)（课程资料）。它们分别偏向工具或资料库；未据此断言 GitHub 上不存在同类一卡教学网站。

## 内容边界

网站中的“可以怎样卡”是结构推演，不是对具体剧集实际一卡位置的断言。红果课程与小红书帖子代表各自作者的分析观点，不应被当作所有平台的统一制作标准。
